# 抖音与小红书解析修复记录

2026-10-03。两条视频的解析修复及真实下载、画质核验已通过。小红书图片下载仍有间歇性失败；当前不应作为“已稳定支持两平台所有内容”或正式上线验收通过的证明。

## 已修改的行为

- 小红书同时读取桌面页面状态和移动端公开页面状态，按当前帖子 ID 匹配内容，比较各编码版本的公开视频画质。
- 抖音读取当前视频的详情响应，忽略空响应及推荐视频；比较默认视频与码率列表，避免误选较低画质。官方短链校验后直接使用浏览器渲染帖子，减少重复加载。
- 浏览器请求保留所需请求头和匿名会话 Cookie，限制 Cookie 域；保留逐跳 URL、安全 DNS 和请求预算校验。
- 从失败请求的临时缓存定位到抖音最高画质地址使用 `v5-dy-ov-experiment.zjcdn.com`。原有媒体域名列表遗漏此别名；仅加入这个实际观察到的别名，不允许任意 `zjcdn.com` 子域。相关测试仍拒绝伪装域名、其他平台及私网 DNS。
- 原图可能是 HEIC，修正被平台声明为 JPEG 的 HEIC 响应识别，以及下载和 ZIP 中的文件扩展名。
- 修正响应体主动关闭引发的未处理流错误；对明确的临时连接错误最多重试一次，使用已校验的 DNS 地址。已经发给用户的下载流不自动重放。
- 解析总时限为 60 秒；浏览器最多 300 个资源请求、8 个同时传输、32 MiB 实际字节预算。

## 验收结果与剩余工作

- 82 项单元测试、类型检查、Lint 和 Docker 生产构建通过。
- 部分浏览器端下载与 ZIP 用例通过；移动端重跑用例通过后测试进程未正常退出，因此不计为完整端到端测试通过。
- CDN 别名修复后的最新一轮 Docker 测试：抖音解析成功（约 36 秒），完整下载 4,394,355 字节 MP4；小红书视频解析成功（约 2 秒），完整下载 4,969,181 字节 MP4。3 张图片均解析成功，2 张完整下载成功，1 张下载返回 502。本轮并非全部通过。
- CDN 别名修复前的一轮测试，小红书视频及 3 张图片曾全部完整下载成功。此前另有抖音解析失败及图片下载 502。
- 前一轮抖音也出现 60 秒解析超时。诊断曾发现 CDN 请求连接、响应头及响应体超时；尚未证明所有失败只有这一个原因。
- 视频样本的实际解析、下载和画质已验证；仍需定位 Docker 中图片下载的间歇性失败并扩充样本。更新体验部署后还需用户复测，本文不代表旧的临时外网页面已更新。
