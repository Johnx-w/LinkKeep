# LinkKeep 双平台技术验证计划

## 1. 目标与止损条件

在开发完整视觉页面前，证明抖音和小红书的公开解析、质量选择和媒体传输可在既定安全、合规、性能与预算边界内工作。

任一平台不能满足以下门槛时，不宣称支持该平台，也不以登录 Cookie、私有接口逆向、stealth 或风控绕过兜底：

- 固定回归样本 10/10 通过。
- 动态有效样本解析成功率不低于 90%。
- 解析成功后的下载启动率不低于 95%。
- 核心安全测试全部通过。

## 2. 已确认测试缝

测试只通过以下公开边界观察行为：

1. **分享输入解析器**：分享文本进入，返回唯一规范化受支持链接或用户可理解错误。
2. **平台适配器契约**：规范化链接进入，返回分享条目及媒体项，或分类后的领域错误。
3. **解析 HTTP API**：访客请求进入，返回临时结果、限额/熔断状态和请求编号。
4. **下载 HTTP API**：媒体令牌进入，开始安全代理流或返回大小、类型、预算等错误。
5. **后台操作 API**：经认证运营者可查看状态、切换平台、处理投诉和停止解析帖子。
6. **浏览器核心流程**：访客可粘贴、解析、预览、选择、直连下载或生成多图 ZIP。

外部平台、时间、DNS 和对象响应在自动化测试中作为系统边界替代；不模拟内部模块，不断言私有函数或调用次数。

## 3. 授权样本清单

用户提供抖音、小红书各 10 条本人发布或明确获授权的公开链接。样本清单放在不提交到 Git 的本地文件 `.private/authorized-samples.json`，仓库只提交 `.private/authorized-samples.example.json`。

每个平台至少覆盖：

- 2 条单图或单媒体帖子。
- 2 条多图帖子。
- 2 条公开视频。
- 2 条官方短链或完整分享文本。
- 1 条标题/作者字段缺失或含特殊字符的帖子。
- 1 条可取得的实况媒体对；若平台当前不提供，则以另一条边界样本替代并记录原因。

每条样本记录：

- 样本编号和平台。
- 授权依据，不存身份证件或无关个人资料。
- 原始输入仅保存在本地私有文件。
- 预期帖子类型、媒体项数量、最小尺寸/格式约束。
- 是否预期公开干净源、是否允许平台分发版。
- 最后人工确认仍公开可访问的时间。

## 4. 自动化验证

### 4.1 输入与安全

- 从纯链接和分享文本提取唯一官方链接。
- 多链接、非 HTTP(S)、用户名密码 URL、混淆主机名和不受支持域名被拒绝。
- 每次重定向重新校验域名；本机、私网、链路本地、保留地址和 DNS 重绑定目标被拒绝。
- 跳转次数、请求时间、响应大小和并发均有硬上限。

### 4.2 平台适配器

- 同一分享条目得到稳定的平台和规范化帖子标识。
- 媒体项包含类型、尺寸、格式、来源、质量和过期信息。
- 多图顺序稳定，实况图片和短视频保持关联。
- 受限、删除、隐藏、停止解析、页面变更和平台限流得到不同领域错误。
- HTTP 路径优先；浏览器兜底无账号、无持久 Cookie、无 stealth，任务后销毁上下文。

### 4.3 传输

- 可直连时返回短期媒体令牌，不把源 URL 放进永久结果 URL 或日志。
- 多图在浏览器本地生成 ZIP，文件名清洗、截断且不发生路径穿越。
- 代理对最终 URL 再做安全校验，并以响应头、文件签名和大小共同验证图片/视频。
- HTML、SVG、脚本、压缩包、可执行文件、伪造 MIME 和超大媒体被拒绝。
- 单项 300 MB、ZIP 800 MB、月度代理预算和 15 分钟过期均强制执行。

### 4.4 限额、日志与后台

- 每个限流标识 5 次/小时、20 次/天，日期轮换后不可形成长期用户标识。
- 风险验证只在高频、重复失败或预算临界条件触发。
- 日志不含完整分享文本、媒体 URL、原始 IP、TOTP 密钥或投诉原文。
- 未认证、仅密码或 CSRF 请求不能执行后台写操作。
- 运营者可单独熔断平台、停止解析指定帖子并清除对应临时结果。

## 5. 手工真实平台验证

对 `.private/authorized-samples.json` 中每条样本：

1. 在无平台登录、空 Cookie 环境提交原始分享输入。
2. 记录展开后的官方平台与帖子标识，不在报告中记录完整媒体 URL。
3. 核对来源归属、媒体项数量、顺序、格式、尺寸和质量说明。
4. 逐项验证直连；多图验证本地 ZIP；选择符合代理条件的样本验证临时代理。
5. 验证 15 秒超时、过期、平台熔断和预算熔断后的用户提示。
6. 在 iOS Safari、Android Chrome/Edge、桌面 Chrome/Edge/Safari 运行核心流程。

结果记录在 `artifacts/validation/latest.json` 和人类可读摘要中；媒体文件、源 URL、Cookie 和个人资料不得进入仓库。

## 6. 动态样本与指标

- 每次候选发布前重新抽取当时确认公开有效的样本。
- 分母仅包含开始测试时无需登录、未删除、未隐藏且平台健康的支持范围内容。
- 解析成功和下载启动分别计数，不能用“展示错误页”计作成功。
- 固定样本用于回归，动态样本用于真实成功率；二者不得混用。

## 7. 完成判定

技术验证完成必须同时具备：

- 自动化测试报告和安全用例全部通过。
- 授权固定样本两个平台分别 10/10 通过。
- 动态样本达到 90% 解析和 95% 下载启动门槛。
- 代理成本估算与熔断演练证明月度上限不会被突破。
- 已知平台能力缺口写入产品界面和验证报告。

若缺少授权样本，只能完成模拟边界和安全测试，不能将平台标记为“验证通过”。
